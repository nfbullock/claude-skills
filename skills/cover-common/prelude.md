# Cover prelude — read the room, then look up the song

Shared by `cover-deconstruct` and `song-recipe`. Do these in order before answering Nick's first message in a cover session. Each skill layers its own mode-specific reads on top (quiz-calibration for deconstruct; vocabulary + reimagining-directions for recipe).

## 1. Read `playground/JOURNAL.md`

You need all of these:

- **Cover phase** — `recipe` (or absent) routes to `song-recipe`; `deconstruct` routes to `cover-deconstruct`. If you're in the wrong skill, stop and route.
- **Songs finished** count — context for how heavy a session to run.
- **Listening skills learned** — the running list. In `cover-deconstruct` it gates quiz difficulty (see `quiz-calibration.md`). In `song-recipe` it tells you which terms Nick has heard already and won't need redefined inline.
- **Notes for the coach** — patterns Nick has shown (struggles with playhead navigation, drums crowd the bass, etc.). Lean on them.
- **Current phase** (Phase 1/2/3) — affects whether you commit to one direction or offer a menu.

## 2. Look up the song (WebSearch)

Find:

- Tempo (BPM)
- Key and mode (e.g., D minor, F# major, A Mixolydian)
- Form (verse/chorus structure, bar counts per section if findable)
- Chord progression (Roman numeral *and* absolute names if findable)
- Melodic range of the lead line (lowest and highest notes, even approximate) — this feeds the vocal-range-fit check when picking the cover's key and tempo (lesson template Section 5)
- Instrumentation
- Production-identity facts (genre, producer, year, recording style)

Good sources: SongBPM, Hooktheory, Tunebat, Wikipedia, Ultimate Guitar tabs. Cross-check at least two — BPM listings disagree often, especially on songs with a halftime feel. **When sources disagree, that's a teaching moment** about why ("the song feels like 70 because the snare is on 3, but the hi-hat is at 140"). In `cover-deconstruct`, save it for the quiz reveal. In `song-recipe`, mention it inline in the breakdown.

## 3. Local-analysis MCP, if available

See `local-analysis.md` for detection and use. Local analysis *complements* the web lookup — the web tells you what listeners agreed on; the local tool tells you what's measurably true in the actual audio file. When they disagree, lean on the analyzer and use the disagreement as the teaching moment.

## 4. Readiness check

If a **contrafact / lyric-rewrite is planned** (Nick said so, or the JOURNAL notes it), flag it now: that plan fires the **lyric & prosody pass** — the scansion grid — in the producer's-ear walkthrough (Pass 5 in `cover-deconstruct/references/listening-layers.md`). Without a planned rewrite that pass is skippable.

If the song is harmonically unusual (modal interchange, key changes, complex meter, non-4/4 time), name what makes it complex in one sentence so Nick knows what's coming. Default to proceeding — the rig version doesn't need to render the complexity faithfully; *Constellation*'s method (`feedback_covers_not_same_style`) allows simplifying or even sidestepping the hard parts as the rig version's actual approach, not as a fallback. Only offer a substitution if Nick is in his first three covers AND the harmonic complexity is the *only* reason he was reaching for the song. Don't gate.

## 5. Build the reference playlist

Build the lesson's reference playlist via the apple-music-playlist skill BEFORE writing the lesson (umbrella mandate — see music/CLAUDE.md "Reference playlist before the next lesson"); skippable only on Nick's say-so.

---

After this prelude, the two skills diverge:

- `cover-deconstruct` asks pacing (quick ~10 min or deep ~25–30) and **does not reveal** what it found — it's about to quiz him.
- `song-recipe` proceeds directly to the breakdown, doing the work in a monologue with inline vocabulary.
